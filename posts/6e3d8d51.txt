<h2 id="什么是git"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#什么是git">#</a>什么是Git?</h2>
<p>Git 已成为版本控制的全球标准。 那么，它到底是什么？</p>
<p>Git 是分布式版本控制系统，这意味着项目的本地克隆是完整的版本控制存储库。 通过这些功能齐全的本地存储库，无论脱机还是远程都能轻松工作。 开发人员在本地提交工作，然后将存储库的副本与服务器上的副本同步。 这种范例不同于集中式版本控制，后者要求客户端必须先与服务器同步代码，然后才能创建新版代码。</p>
<p>Git 的灵活性和受欢迎程度使其成为任何团队的绝佳选择。 许多开发人员和大学毕业生已经知道如何使用 Git。 Git 的用户社区已创建资源来训练开发人员和 Git 的受欢迎程度，以便在需要时轻松获取帮助。 几乎每个开发环境都有 Git 支持和 Git 命令行工具在每个主要操作系统上实现。</p>
<h2 id="git基础知识"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#git基础知识">#</a>Git基础知识</h2>
<p>每次保存工作时，Git 都会创建提交。 提交是某个时间点所有文件的快照。 如果文件未从一个提交更改为下一个提交，Git 将使用以前存储的文件。 此设计不同于存储文件的初始版本并随时间推移保留增量记录的其他系统。</p>
<p>提交创建指向其他提交的链接，形成开发历史记录的图。 可以将代码还原到以前的提交，检查文件如何从一个提交更改为下一个提交，并查看更改的位置和时间等信息。 提交通过提交内容的唯一加密哈希在 Git 中标识。 由于所有内容都经过哈希处理，因此在未检测到 Git 的情况下无法进行更改、丢失信息或损坏文件。</p>
<h2 id="分支"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#分支">#</a>分支</h2>
<p>每个开发人员将更改保存到自己的本地代码存储库。 因此，根据同一提交，可能会进行许多不同的更改。 Git 提供了用于隔离更改并在以后将它们重新合并在一起的工具。 分支是用于工作的轻型指针，可管理此分离。 在分支中创建的工作完成后，可以合并回团队的主分支（或主干）。</p>
<h2 id="文件和提交"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#文件和提交">#</a>文件和提交</h2>
<p>Git 中的文件处于以下三种状态之一：已修改、暂存或提交。 首次修改文件时，更改仅存在于工作目录中。 它们尚不属于提交或开发历史记录。 开发人员必须 暂存 提交中要包含的已更改文件。 暂存区域包含下一个提交中要包括的所有更改。 开发人员对暂存文件感到满意后，文件将打包为 提交 ，其中包含描述更改的内容的消息。 此提交将成为开发历史记录的一部分。</p>
<p>暂存允许开发人员选择要在提交中保存的文件更改，以便将大型更改分解为一系列较小的提交。 通过减少提交范围，可以更轻松地查看提交历史记录以查找特定文件更改。</p>
<h2 id="git的优势"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#git的优势">#</a>Git的优势</h2>
<h3 id="同时开发"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#同时开发">#</a>同时开发</h3>
<p>每个人都有自己的本地代码副本，并且可以在自己的分支上同时工作。 Git 脱机工作，因为几乎所有操作都是本地操作。</p>
<h3 id="更快的版本"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#更快的版本">#</a>更快的版本</h3>
<p>分支允许灵活且同时进行开发。 主分支包含发布的稳定、高质量的代码。 功能分支包含正在进行的工作，这些工作在完成后合并到主分支中。 通过将发布分支与正在进行的开发分开，可以更轻松地管理稳定的代码并更快地交付更新。</p>
<h3 id="内置集成"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#内置集成">#</a>内置集成</h3>
<p>由于它的受欢迎程度，Git 集成到大多数工具和产品中。 每个主要 IDE 都有内置的 Git 支持，许多工具都支持持续集成、持续部署、自动测试、工作项跟踪、指标和报告功能与 Git 集成。 此集成简化了日常工作流。</p>
<h3 id="强大的社区支持"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#强大的社区支持">#</a>强大的社区支持</h3>
<p>Git 是开源的，已成为版本控制的事实标准。 团队利用的工具和资源并不短缺。 与其他版本控制系统相比，社区对 Git 的支持量使得在需要时可以轻松获取帮助。</p>
<h3 id="git与任何团队合作"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#git与任何团队合作">#</a>Git与任何团队合作</h3>
<p>通过鼓励协作、强制实施策略、自动化流程以及提高工作的可见性和可追溯性，将 Git 与源代码管理工具配合使用可以提高团队的工作效率。 团队可以针对各个工具进行版本控制、工作项跟踪以及持续集成和部署。 或者，他们可以选择一个解决方案，例如<a href="https://github.com/">GitHub</a>或<a href="https://azure.microsoft.com/zh-cn/products/devops/repos/">Azure DevOps</a> ，该解决方案支持所有这些任务。</p>
<h3 id="拉取请求"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#拉取请求">#</a>拉取请求</h3>
<p>在将代码更改合并到主分支之前，请使用<a href="https://learn.microsoft.com/zh-cn/devops/develop/git/git-pull-requests">拉取请求</a>与团队讨论代码更改。 拉取请求中的讨论对于确保代码质量并提高团队的知识非常重要。 GitHub 和 Azure DevOps 等平台提供了丰富的拉取请求体验，开发人员可以浏览文件更改、留下批注、检查提交、查看生成和投票以批准代码。</p>
<h3 id="分支策略"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#分支策略">#</a>分支策略</h3>
<p>Teams 可以将 GitHub 和 Azure DevOps 配置为在整个团队中强制实施一致的工作流和流程。 他们可以设置<a href="https://learn.microsoft.com/zh-cn/azure/devops/repos/git/branch-policies?view=azure-devops&#x26;tabs=browser">分支策略</a>，以确保拉取请求满足完成前的要求。 分支策略通过防止直接推送、要求审阅者并确保干净生成来保护重要分支。</p>
<h2 id="常用git命令清单"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#常用git命令清单">#</a>常用Git命令清单</h2>
<p>在开始使用Git之前，我们需要先安装Git软件。Git是一个分布式版本控制系统，支持在Linux/Unix、Solaris、Mac和Windows等多个平台上运行。</p>
<p>你可以从git-scm.com/downloads这个网站下载适合你操作系统的Git安装包。如果你的系统是Windows，你可以访问npm.taobao.org/mirrors/git来下载安装Git。安装Git后，你还需要进行一些配置来使其正常工作。</p>
<p>以上是使用Git前需要安装Git软件的概述，具体的安装和配置过程可以参考菜鸟教程（runoob.com）上的相关指南。</p>
<p>以下Git命令转载自稀土掘金<a href="https://juejin.cn/post/7133507623399194661#heading-4"><strong>奇想派</strong></a>，侵权请联系站长删除。</p>
<h2 id="创建仓库命令"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#创建仓库命令">#</a>创建仓库命令</h2>

<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git init</span></span></code></span>: 初始化仓库就是在当前目录下创建一个.git目录，用于存储Git所需的元数据和文件版本记录。该目录包含了objects、refs/head、refs/tags和模板文件等基本部分。</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git clone [url]</span></span></code></span>: 拷贝一份远程仓库，也就是下载一个项目和它的整个代码历史。</p>
</li>
</ul>

<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git config --list</span></span></code></span>: 显示当前的Git配置</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git config -e [--global]</span></span></code></span>: 编辑Git配置文件</p>

<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git config [--global] user.name "[name]" / git config [--global] user.email "[email address]"</span></span></code></span>: 设置提交代码时的用户信息</p>

</ul>
<h2 id="增加删除文件"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#增加删除文件">#</a>增加/删除文件</h2>
<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git add [file1] [file2] ...</span></span></code></span>: 添加指定文件到暂存区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git add [dir]</span></span></code></span>: 添加指定目录到暂存区，包括子目录</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git add .</span></span></code></span>: 添加当前目录的所有文件到暂存区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git add -p</span></span></code></span>: 添加每个变化前，都会要求确认，对于同一个文件的多处变化，可以实现分次提交</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git rm [file1] [file2] ...</span></span></code></span>: 删除工作区文件，并且将这次删除放入暂存区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git rm --cached [file]</span></span></code></span>: 停止追踪指定文件，但该文件会保留在工作区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git mv [file-original] [file-renamed]</span></span></code></span>: 改名文件，并且将这个改名放入暂存区</p>
</li>
</ul>
<h2 id="代码提交"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#代码提交">#</a>代码提交</h2>
<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit -m [message]</span></span></code></span>: 提交暂存区到仓库区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit [file1] [file2] ... -m [message]</span></span></code></span>: 提交暂存区的指定文件到仓库区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit -a</span></span></code></span>: 提交工作区自上次commit之后的变化，直接到仓库区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit -v</span></span></code></span>: 提交时显示所有diff信息</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit --amend -m [message]</span></span></code></span>: 使用一次新的commit，替代上一次提交。如果代码没有任何新变化，则用来改写上一次commit的提交信息</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git commit --amend [file1] [file2] ...</span></span></code></span>: 重做上一次commit，并包括指定文件的新变化</p>
</li>
</ul>
<h2 id="分支-1"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#分支-1">#</a>分支</h2>
<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch</span></span></code></span>: 列出所有本地分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch -r</span></span></code></span>: 列出所有远程分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch -a</span></span></code></span>: 列出所有本地分支和远程分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch [branch-name]</span></span></code></span>: 新建一个分支，但依然停留在当前分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout -b [branch]</span></span></code></span>: 新建一个分支，并切换到该分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch [branch] [commit]</span></span></code></span>: 新建一个分支，指向指定commit</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch --track [branch] [remote-branch]</span></span></code></span>: 新建一个分支，与指定的远程分支建立追踪关系</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout [branch-name]</span></span></code></span>: 切换到指定分支，并更新工作区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout -</span></span></code></span>: 切换到上一个分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch --set-upstream [branch] [remote-branch]</span></span></code></span>: 建立追踪关系，在现有分支与指定的远程分支之间</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git merge [branch]</span></span></code></span>: 合并指定分支到当前分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git cherry-pick [commit]</span></span></code></span>: 选择一个commit，合并进当前分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git branch -d [branch-name]</span></span></code></span>: 删除分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git push origin --delete [branch-name] 或 git branch -dr [remote/branch]</span></span></code></span>: 删除远程分支</p>
</li>
</ul>

</li>

<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git tag -d [tag]</span></span></code></span>: 删除本地tag</p>

<h2 id="查看信息和历史"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#查看信息和历史">#</a>查看信息和历史</h2>
<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git status</span></span></code></span>: 显示有变更的文件</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log</span></span></code></span>: 显示当前分支的版本历史</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log --stat</span></span></code></span>: 显示commit历史，以及每次commit发生变更的文件</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log -S [keyword]</span></span></code></span>: 搜索提交历史，根据关键词</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log [tag] HEAD --pretty=format:%s</span></span></code></span>: 显示某个commit之后的所有变动，每个commit占据一行</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log [tag] HEAD --grep feature</span></span></code></span>: 显示某个commit之后的所有变动，其"提交说明"必须符合搜索条件</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log --follow [file] 或 git whatchanged [file]</span></span></code></span>: 显示某个文件的版本历史，包括文件改名</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log -p [file]</span></span></code></span>: 显示指定文件相关的每一次diff</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git log -5 --pretty --oneline</span></span></code></span>: 显示过去5次提交</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git shortlog -sn</span></span></code></span>: 显示所有提交过的用户，按提交次数排序</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git blame [file]</span></span></code></span>: 显示指定文件是什么人在什么时间修改过</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git diff</span></span></code></span>: 显示暂存区和工作区的差异</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git diff --cached [file]</span></span></code></span>: 显示暂存区和上一个commit的差异</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git diff HEAD</span></span></code></span>: 显示工作区与当前分支最新commit之间的差异</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git diff [first-branch]...[second-branch]</span></span></code></span>: 显示两次提交之间的差异</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git diff --shortstat "@{0 day ago}"</span></span></code></span>: 显示今天你写了多少行代码</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git show [commit]</span></span></code></span>: 显示某次提交的元数据和内容变化</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git show --name-only [commit]</span></span></code></span>: 显示某次提交发生变化的文件</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git show [commit]:[filename]</span></span></code></span>: 显示某次提交时，某个文件的内容</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reflog</span></span></code></span>: 显示当前分支的最近几次提交</p>
</li>
</ul>

<li>

</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git config [--global] user.name "[name]" / git config [--global] user.email "[email address]"</span></span></code></span>: 设置提交代码时的用户信息</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git remote show [remote]</span></span></code></span>: 显示某个远程仓库的信息</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git remote add [shortname] [url]</span></span></code></span>: 增加一个新的远程仓库，并命名</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git pull [remote] [branch]</span></span></code></span>: 取回远程仓库的变化，并与本地分支合并</p>

</li>
<li>

</li>
</ul>
<h2 id="撤销"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#撤销">#</a>撤销</h2>
<ul>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout [file]</span></span></code></span>: 恢复暂存区的指定文件到工作区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout [commit] [file]</span></span></code></span>: 恢复某个commit的指定文件到暂存区和工作区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git checkout .</span></span></code></span>: 恢复暂存区的所有文件到工作区</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reset [file]</span></span></code></span>: 重置暂存区的指定文件，与上一次commit保持一致，但工作区不变</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reset --hard</span></span></code></span>: 重置暂存区与工作区，与上一次commit保持一致</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reset [commit]</span></span></code></span>: 重置当前分支的指针为指定commit，同时重置暂存区，但工作区不变</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reset --hard [commit]</span></span></code></span>: 重置当前分支的HEAD为指定commit，同时重置暂存区和工作区，与指定commit一致</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git reset --keep [commit]</span></span></code></span>: 重置当前HEAD为指定commit，但保持暂存区和工作区不变</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git revert [commit]</span></span></code></span>: 新建一个commit，用来撤销指定commit。后者的所有变化都将被前者抵消，并且应用到当前分支</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git stash</span></span></code></span>: 暂时将未提交的变化移除，稍后再移入</p>
</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>git stash pop</span></span></code></span>: 暂时将未提交的变化移除，稍后再移入</p>
</li>
</ul>
