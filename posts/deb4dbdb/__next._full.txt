<h2 id="分栏-tab"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#分栏-tab">#</a>分栏 tab</h2>
<div class="hexo-note">
<p>分栏支持内置阿里图标，如果开启了 <span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>fontawesome</span></span></code></span>可以使用 fontawesome 的图标，否则只能使用默内置阿里图标</p>
</div>
<!-- tab 标签语法 -->
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="markdown" data-theme="github-light-default github-dark-default"><code data-language="markdown" data-theme="github-light-default github-dark-default" style="display: grid;"><span data-line=""><span style="--shiki-light:#1F2328;--shiki-dark:#E6EDF3">{% tabs Unique name, [</span><span style="--shiki-light:#0A3069;--shiki-dark:#A5D6FF">index</span><span style="--shiki-light:#1F2328;--shiki-dark:#E6EDF3">] %}</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#6E7781;--shiki-dark:#8B949E">&#x3C;!-- tab [Tab caption] [@icon] --></span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#1F2328;--shiki-dark:#E6EDF3">Any content (support inline tags too).</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#6E7781;--shiki-dark:#8B949E">&#x3C;!-- endtab --></span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#1F2328;--shiki-dark:#E6EDF3">{% endtabs %}</span></span></code></pre></figure>
<!-- endtab -->
<!-- tab 配置参数 -->
<ol>
<li>Unique name :
<ul>
<li>选项卡块标签的唯一名称，不带逗号。</li>
<li>将在#id 中用作每个标签及其索引号的前缀。</li>
<li>如果名称中包含空格，则对于生成#id，所有空格将由破折号代替。</li>
<li>仅当前帖子/页面的 URL 必须是唯一的！</li>
</ul>
</li>
<li>[index]:
<ul>
<li>活动选项卡的索引号。</li>
<li>如果未指定，将选择第一个标签（1）。</li>
<li>如果 index 为-1，则不会选择任何选项卡。</li>
<li>可选参数。</li>
</ul>
</li>
<li>[Tab caption]:
<ul>
<li>当前选项卡的标题。</li>
<li>如果未指定标题，则带有制表符索引后缀的唯一名称将用作制表符的标题。</li>
<li>如果未指定标题，但指定了图标，则标题将为空。</li>
<li>可选参数。</li>
</ul>
</li>
<li>[@icon]: - FontAwesome 图标名称（全名，看起来像“ fas fa-font”） - 可以指定带空格或不带空格； - 例如'Tab caption @icon' 和 'Tab caption@icon'. - 可选参数。
<!-- endtab -->
<!-- tab 样式预览 -->
</li>
</ol>

<div class="hexo-note">
<p>思维拓展一下，相册图库的实质其实就是个快捷方式，可以自定义添加描述、封面、链接。那么我们未必要把它当做一个相册，完全可以作为一个链接卡片，链接到视频、QQ、友链都是不错的选择。</p>
</div>
<ul>
<li>gallery 相册
区别于旧版的 Gallery 相册,新的 Gallery 相册会自动根据图片长度进行排版，书写也更加方便，与 markdown 格式一样。可根据需要插入到相应的 md。无需再自己配置长宽。<strong>建议在粘贴时故意使用长短、大小、横竖不一的图片</strong>，会有更好的效果。（尺寸完全相同的图片只会平铺输出，效果很糟糕）</li>

<h2 id="tag-hide"><a class="heading-anchor" data-anchor-copy="true" aria-label="复制本节链接" href="#tag-hide">#</a>tag-hide</h2>
<div class="hexo-note">
<p>如果你想把一些文字、内容隐藏起来，并提供按钮让用户点击显示。可以使用这个标签外挂。
请注意，tag-hide内的标签外挂content内都不建议有h1 - h6 等标题。因为Toc会把隐藏内容标题也显示出来，而且当滚动屏幕时，如果隐藏内容没有显示出来，会导致Toc的滚动出现异常。</p>
</div>
<!-- tab inline -->
<p><span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>inline</span></span></code></span> 在文本里面添加按钮隐藏内容，只限文字</p>
<p>( content不能包含英文逗号，可用<span data-rehype-pretty-code-figure=""><code data-language="text" data-theme="github-light-default github-dark-default"><span data-line=""><span>&#x26;sbquo;</span></span></code></span>)</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="markdown" data-theme="github-light-default github-dark-default"><code data-language="markdown" data-theme="github-light-default github-dark-default" style="display: grid;"><span data-line=""><span style="--shiki-light:#1F2328;--shiki-dark:#E6EDF3">{% hideInline content,display,bg,color %}</span></span></code></pre></figure>
<ul>
<li>
<p>content: 文本内容</p>
</li>
<li>
<p>display: 按钮显示的文字(可选)</p>
</li>
<li>
<p>bg: 按钮的背景颜色(可选)</p>
</li>
<li>
<p>color: 按钮文字的颜色(可选)</p>
</li>
</ul>
